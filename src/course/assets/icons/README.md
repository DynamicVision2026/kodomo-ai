# ナゼホリ course tool icons (locked, AD-18)

Six tool icons for the formal course. They are locked: don't redraw them or change the colours.

| Tool | File | Object | Child label |
|---|---|---|---|
| A | tool-A-bento.svg | おべんとうばこ | ふたを あける |
| B | tool-B-domino.svg | ドミノ | まえの りゆうを 見る |
| C | tool-C-step-stool.svg | ふみ台 | ふみ台を 見る |
| D | tool-D-umbrella.svg | かさ | はみだしを さがす |
| E | tool-E-eraser.svg | けしゴム | ひとつ けして かく |
| F | tool-F-seesaw.svg | シーソー | むこうに すわる |

- Grid: 48 × 48, 3-unit rounded stroke.
- Colours are fixed inside the files: navy line #1B1F3A, white body #FFFFFF, and one yellow part #FFD23F. The yellow part marks "where to look".
- In dark mode, place each icon on a light tile (the design pages use a #FFFFFF tile with a #D6DAE7 border). Don't recolour the icon itself.
- Sizes used in the designs: 96 px on cards, 32 px on buttons, 22–24 px inline. Don't go below 24 px.
- The sprite `tool-icons.sprite.svg` has ids `tool-A` … `tool-F`, for use with `<use href="#tool-A"/>`.
- Accessible names: use the Japanese object name and label, e.g. 「おべんとうばこ（ふたを あける）」.
