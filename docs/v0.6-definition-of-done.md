## Critical rule (do not violate)

From the commit that freezes this document onward, v0.6 progress is reported **only** against
the seven packages and weights below, which total exactly 100 points. A newly discovered
requirement is never a reason to add an eighth package or reweight the existing seven. Classify
it instead:

- **A. Already inside one of the seven packages** → it consumes that package's own existing
  weight (its "remaining requirements" list grows; the package's weight does not).
- **B. Genuinely new scope** → v0.7 / a later phase, unless the Founder explicitly amends this
  document (a new commit, not a silent drift).

There is no Package 8.
